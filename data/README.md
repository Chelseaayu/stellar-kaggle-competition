# Data Directory

Place the competition data files here:

- `train.csv`
- `test.csv`
- `sample_submission.csv`

Download from: https://www.kaggle.com/competitions/playground-series-s6e6/data

```bash
# Using Kaggle CLI:
kaggle competitions download -c playground-series-s6e6
unzip playground-series-s6e6.zip -d data/
```

> **Note**: These files are `.gitignore`'d and not committed to the repository.
